# 09.02.07.- Каталог образовательных программ + Форум для общения специалистов

О проекте:
Это онлайн-платформа для IT-специалистов, объединяющая каталог образовательных программ (курсов, направлений, навыков) и форум для обмена опытом. Ее основная идея - помочь специалистам выбрать подходящие учебные курсы и обсудить профессиональные темы на одной платформе.

Стек технологий:
Backend: Python 3.13, Django 6.0.3, Django REST Framework, PostgreSQL 17
Frontend: React, Vite 8.0.1, Node.js 18.0+, npm 9.0+
DevOps: Docker, docker-compose, Git, pytest
API: JWT-аутентификация, Swagger (drf-yasg), CORS
Доп: django-filter, ReportLab/WeasyPrint (экспорт в PDF)
